# 2026 大学生「AI+信息素养」大赛 · 备赛项目

把官方命题范围与竞赛平台真题合并成一套**可秒查的统一题库**，并把 50 个知识模块的备考要点整理成一张工作台。

> 题库依据《2026 年大学生"AI+信息素养"大赛客观题命题范围及备赛建议》**2026.9.10 修订版**
> 竞赛平台：智信数图知识竞赛平台（`js.zhixinst.com`）

## 使用方式

### 一、网页版（推荐）

直接打开 `qbank.html`，或访问 GitHub Pages 首页的「题库检索」。
单文件、离线可用，粘贴题目即可。

### 二、命令行

```bash
cd _work/qbank

python 搜题.py "本位码"                      # 全库检索
python 搜题.py "思维导图" --src official      # 只查官方样题
python 搜题.py "VLOOKUP" --src platform --type multi   # 只查平台多选题
python 搜题.py "一稿多投" --top 5             # 返回前 5 条
```

参数：`--src`(platform / official / both) · `--pool`(A / B / C / O) · `--type`(single / multi / judge) · `--top`

## 数据字段说明（`bank.json`）

| 字段 | 含义 |
|---|---|
| `id` | 题号，如 `A07`（平台 A 题库第 7 题）、`O12`（官方第 12 题）、`M01`（重合题） |
| `src` | `platform` / `official` / `both` |
| `pool` | 平台题库归属 A / B / C；官方题为 `O` |
| `type` | `single` / `multi` / `judge` |
| `stem` | 题干 |
| `options` | 选项 `[{k, v}]` |
| `answer` | 正确答案字母 |
| `expl` | 官方解析（含推荐检索路径） |
| `module` | 官方题所属知识模块 `[编号, 名称]` |
| `vols` | 该题出现在哪些卷中 |
| `variants` | 重合题的另一版本（选项与答案） |
| `merge_note` | 重合题的差异说明 |

## ⚠️ 使用前必读

**1. 同一套题库每次进入，题目顺序与选项顺序都会重新打乱。**

所以必须按**题干内容**检索，不要背「第 N 题选 X」。
同一道万方题先后出现过 `A=D/B=B/C=C/D=J` 与 `A=C/B=B/C=D/D=J` 两种排布。

**2. 作答请按选项内容判定，不要只记字母。**

正确写法是「正确内容 = X，对应本题第 Y 项」。

**3. 两道重合题的答案字母不同，但都成立 —— 原因不同：**

| ID | 题目 | 情况 |
|---|---|---|
| `M01` | 云展网 PDF 工具提供的功能 | **选项内容本身有差异**：官方版 A =「PDF 转 Word」判对（答案 ABCD）；平台版 A =「PDF 去水印」判错（答案 BCD） |
| `M02` | 百度高级检索中「关键词位置」的可选项 | **选项顺序被打乱**：字母看似冲突（官方 ABC vs 平台 ACD），按内容核对后完全一致 |

**4. 检索算法说明。**

字符二元组 + TF-IDF 余弦相似度打分，再用**最长公共子串（LCS）**门控
（要求与题目有 ≥ `min(查询长度, 4)` 个连续字符重合）。
因此乱码或无关查询会明确返回「未命中」，而不是硬凑一个低分结果。
返回「未命中」即表示题库确实没有这道题。
